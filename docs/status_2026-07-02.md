## Freeze discipline — momentum_breakout (and now relative_strength)

**No signal-logic changes until the forward test reaches 30–50 trades per sleeve.**
At the current 4-trade sample (0W/4L realized ≈ −$113), any conclusion — positive or
negative — is noise; the single most dangerous available move is tweaking the entry
rule in reaction to early results (strategy hopping / multiple-testing).

- **Exempt:** risk plumbing (gates, sizing caps, exit mechanics), data-pipeline
  fixes, observability. Today's regime gate is in this class — it changes *when the
  bot may trade at all*, not *what a valid setup is*.
- **Overlay adoptions are NOT exempt** — an overlay changes the entry distribution.
  The pre-registered bar (overlay_search): bootstrap PF CI lower bound > 1.0, PF > 1
  in all three time-thirds, AND clearly beats mb_base's CI — not a nudge.
- Every backtest variant run is reported in the harness output (variant count feeds
  the multiple-testing prior, Deflated-Sharpe logic).
